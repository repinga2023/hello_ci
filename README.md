# Hello World CLI


Простое консольное приложение, которое выводит "Hello world!" в разных регистрах.


# 🚀 Использование

После установки доступна команда hello:

## Простой вывод
`./hello`

## В верхнем регистре
`./hello --mode=upper`

## В нижнем регистре
`./hello --mode=lower`

## В формате заголовка
`./hello --mode=title`

# 🛠 Разработка

1. Клонируйте репозиторий:
```
      git clone https://gitlab.com/your-username/hello-world-cli.git
      cd hello-world-cli
```


2. Установите зависимости для разработки:
      `pip install -e .[dev]`


3. Запустите тесты:
      `pytest`


4. Проверьте стиль кода:
      `flake8 .`


# 🧪 Тестирование

Проект использует pytest для тестирования. Запустите тесты командой:

`pytest --cov=hello`

# 📦 Сборка пакета

Чтобы собрать пакет, выполните:

`python -m build`

Собранные пакеты будут находиться в папке dist/.
